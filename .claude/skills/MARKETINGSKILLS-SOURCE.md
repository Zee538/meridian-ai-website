# Source of the vendored marketing skills

Every skill folder in this directory except `meridian-marketing-agent/` is copied unchanged
(evals folders left out) from https://github.com/coreyhaines31/marketingskills
at commit 5b2b400 (2026-11-19). MIT licensed; see MARKETINGSKILLS-LICENSE.

To update: re-clone that repo and copy its `skills/` folder over this one,
or run `npx skills add coreyhaines31/marketingskills` on your own machine.
